# 阿莉的图 · 一体化发展施工图

> 版本：v1.0 ｜ 制定日期：2026-08-26  
> 核心思路：把"软件免费引流"（方案一想）和"防摔固定盖捆绑"（方案二想）合并成一个闭环——  
> **软件做流量入口 + 硬件需求验证器，固定盖做后期利润放大器。两者共享同一品牌、同一用户池、同一小程序载体。**  
> 顺序：软件先行、硬件验证后行；但固定盖的设计/样品/预售准备可以和软件引流**并行**启动。

 

---

## 0. 总体逻辑图

```
[免费软件·四端] ──引流──> [品牌账号 小红书/闲鱼/小程序]
        │                        │
        │ 导出成功弹问卷          │ 内容晒图带二维码回流
        ▼                        ▼
[用户池 + 付费意愿数据] <───────┘
        │
        │ 阶段2：加"付费功能"变现 + 用数据验证固定盖需求
        ▼
[固定盖 3D打印小批量预售] ──闸门──> 达标则开模量产 ──> [捆绑套装 + 线下门店授权/批发]
```

一句话：**软件先圈人、再小钱变现、同时替硬件投票；硬件验证过了才砸开模的钱。**

## 4. 变现模型优先级（结论）

1. **个人端小额付费（前期低价）**（去水印/批量/高清）—— 阶段2，¥1.99/月或¥9.9永久的轻量档，增长优先、靠硬件变现，暂不限制免费次数
2. **门店买断 / 年度授权**（桌面版打包）—— 阶段3，B2B 最稳
3. **固定盖销售 / 批发** —— 阶段2验证、阶段3放量
4. **抽成** —— 仅当你做"图纸交易平台"（让别人在你这卖图）时才考虑，否则不做（拼豆买卖发生在淘宝/拼多多，你握不住交易）

## 4.5 开模量化门槛：到底依据什么定

开模（注塑）单笔几万~十几万，是最大不可逆投入。闸门不该拍脑袋写"200 单"，而应看**需求强度 + 单位经济 + 渠道确定性**三件事：

1. **需求强度（量）**：预售/众筹累计订单数 + 曝光→下单转化率。没有真实付款，模型再好也别投。
2. **单位经济（价）**：单件成本 = 材料+加工+包装+物流；目标售价；单件毛利 = 售价−成本。模具费要靠毛利摊：需卖 `模具费 ÷ 单件毛利` 件才回本。
3. **渠道确定性（销）**：是否有 ≥2 家线下店/经销商承诺铺货，或线上自然转化已稳定。
4. **现金流安全**：模具费占可用资金比例；即便失败，是否在可承受范围。

**可操作阈值（建议，待你确认）**：
```
回本件数 = 模具费 ÷ 单件毛利
开模条件 = 累计预售 ≥ 回本件数 × 1.5（安全垫）  且   30 日转化率 > 3%  且   有 ≥2 家门店意向
```
举例：模具 ¥30,000、单件毛利 ¥6 → 回本 5000 件，闸门设「累计预售 ≥ 7500 件（或等价渠道订单）」才开模；达不到就继续 3D 打印按需供货，不开模。

## 5. 关键风险与闸门

- **硬件开模是最大单笔投入** → 必须阶段2验证通过才投，绝不提前。
- **网页 WASM 未编译** → 标注精度差异，避免用户预期错位导致差评。
- **小程序需审核/类目** → 提前确认"工具类"类目，避免上线卡审。
- **内容账号需持续运营** → 排期表我可出，但发布动作需你本人（人设/互动）。
- **固定盖 CAD 不在仓库** → 阶段0第一步就是定位+归档，否则后续全卡住。
