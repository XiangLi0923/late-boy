## 中午：修复"图纸色号错误"（运营反馈核心 bug）

**根因**：`mard_all.json`（来源 mard-291-github / HansBug）与 Mard 官方色卡不符——291 色中 274 个 hex 有偏差，其中 22 个严重错误（Δ>10，最大 Δ50，如 G8 深棕 vs 官方红棕、P19 粉白 vs 官方米白、R6 整体色相偏移）。用户按图纸色号买珠子/对色卡即报错。

**验证方法**：抓取三方互证参照（pindou.online ≈ pd.anqstar.com 的 A–M 221 色 + bitbead.pomodiary.com 的 P/Q/R/T/Y/ZG 70 色），逐色号比对 max-channel 偏差。

**修复**：
- 全量修正 hex 至参照值，version 4.0 → 4.1，description 注明修正来源
- 名字矛盾两条手动修正：P19→"米白"、E17→"浅粉"
- 同步 5 处数据：web/public/palettes、engine/palettes/mard_all、mard_{24,48,96} 子集、miniapp paletteData.js（重跑 build_miniapp_palette.js）
- 顺带修了 build_miniapp_palette.js 不兼容 BOM 的老 bug（engine JSON 带 UTF-8 BOM，Node JSON.parse 会炸）
- 前端测试 3/3 ✓、C++ 40/40 ✓、web 重建重新部署 ✓、线上 mard_all.json 已验证为 4.1 修正版 ✓
