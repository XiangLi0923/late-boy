## 用户反复强调的核心规格（重要！）

用户三次粘贴同一份「拼豆图纸转换器」规格，是本程序必须遵守的验收标准：

1. **参考色卡** = 完整官方色卡（色号、名称、RGB），**不允许自创任何色号/编码**。
2. **流程**：① 图片缩小到目标网格（如 45×45），每格一颗豆 → ② 每格取平均 RGB，与色卡全部颜色算**欧氏距离**，匹配最近官方色 → ③ 输出 JSON：`width`、`height`、`grid` 二维数组（存色卡下标）、`color_table`（官方色号/名称/rgb）。
3. **不要简化色卡、不要自创编码**；找不到完全一致就用最接近条目。

> 注：**已统一（2026-08-14）**：网页/桌面版与 C++ 引擎现在都用 **CIELAB ΔE（CIE76）**。CIELAB 的 ΔE 本质就是「感知色空间（Lab）里的欧氏距离」，比原始 RGB 欧氏更符合人眼；RGB 欧氏会把肤色等感知相近色匹配到错误官方色号。这也满足规格「欧氏距离」的本意。

## 关机后如何恢复

> ⚠️ **踩坑记录（重要）**：本项目的 bat 文件必须用 **CRLF 换行**（Claude 的 Write 工具默认写 LF，会让 cmd 乱解析）；bat 里 `start` 命令**别用中文绝对路径**（会静默失败），要先 `cd` 进目录再用相对路径。文档类文件（本 md、README.md、一键启动.bat 等）已被移到 `阿莉工作记录\` 子文件夹。

### 1. 打开桌面应用（推荐）
双击项目根目录 **`启动桌面版.bat`** → 直接弹独立窗口。
（依赖已装好；若换机器需在 `frontends\desktop` 跑
`set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 再 `npm install --registry=https://registry.npmmirror.com`）

### 2. 打开网页开发版
双击 **`一键启动.bat`** → 启动 Vite + 浏览器 `http://localhost:5173/`

### 3. 改了前端代码后要重新同步桌面版
```powershell
cd frontends\web
npm run build
# 然后把 dist 拷到 desktop\renderer\（删旧 renderer 再拷）
```

### 4. 重编译 C++ 引擎 + CLI（改了 C++ 才需要）
```powershell
cmake --build "build-native" --config Release
```

### 5. 运行测试
```powershell
& "build-native\tests\perler_tests.exe"
```
