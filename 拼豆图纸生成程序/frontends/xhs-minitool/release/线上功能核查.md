# 小红书线上功能核查

核查日期：2026-09-18

## 能确认的事实

1. 你给的小红书分享链接返回的是海报分享页，页面内只包含一张静态工具封面和 App 跳转信息，没有公开的小工具 HTML、ZIP 或源码下载入口。
2. 项目正式网页版 `frontends/web/src/App.tsx` 明确渲染了图像调整、主体分割、色卡和抖动面板，这些功能不是从未开发。
3. 项目正式网页构建产物使用 ES module、Service Worker、动态导入，并包含 WASM、Web Worker、网络请求和 ONNX 模型路径。
4. 小红书官方打包规范明确禁止外部网络请求、WebAssembly、Worker、`type="module"` 和动态导入。
5. 项目微信小程序版当前只保留了简化色卡、抖动和“去背景（只保留主体）”，没有正式网页版的完整图像调整面板和 AI 模型。

## 判断

从现有证据看，线上版不是正式网页版某个 CSS 断点把面板“隐藏”了，而是使用了一个单独适配过的简化包或构建链。功能表现为“被删除”，本质更可能是上线时为了适配小红书离线容器而删减了不兼容模块，而不是小红书店方后台单独把四个按钮隐藏。

由于无法从分享链接获取线上 ZIP，当前不能百分之百证明小红书店方是否还保留了未展示代码，但可以确认：正式网页版原构建包即使上传，也不会正常工作，因为它包含容器明确禁止的模块、Worker 和 WASM。

## 本次处理

新增 `frontends/xhs-minitool/`，按官方离线 H5 规范重建界面与流程：

- 色卡选择恢复；
- 色板预览恢复；
- 无抖动、Floyd-Steinberg、Bayer 8x8 恢复；
- 图像调整恢复；
- 网格尺寸、缩放、色号、镜像、颜色用量恢复；
- 主体分割恢复为纯 JS 兜底方案；
- 保存到相册改用 `window.xhs.miniTool`。
